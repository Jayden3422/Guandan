这是一个带脚本的 [Tabletop Simulator](https://store.steampowered.com/app/286160/Tabletop_Simulator/) 掼蛋牌桌，四人、两副牌。它加入了一键发牌和收牌、只有自己看得见的出牌区、点牌出牌，以及像手机掼蛋那样把手牌按点数竖着摞起来的功能。

本 mod 不判断掼蛋规则。它只负责摆牌，牌型和大小由玩家自己判断。

## 基于的原作

本 mod 是在创意工坊 mod **[Guandan](https://steamcommunity.com/sharedfiles/filedetails/?id=3138177412)** 的基础上继续制作的。牌桌、牌、座位和原有的工具都来自原作。

## 安装

**从 Steam 创意工坊（最方便）：** 订阅 [Guandan 掼蛋](https://steamcommunity.com/sharedfiles/filedetails/?id=3812889038)。进游戏开一张桌子，打开 **Games → Workshop**，载入它。

**从本仓库：**

1. 下载 [`workshop/3138177412.json`](workshop/3138177412.json) 和 [`workshop/3138177412.png`](workshop/3138177412.png)。
2. 把两个文件放进 Tabletop Simulator 的存档文件夹：`文档/My Games/Tabletop Simulator/Saves`。
3. 进游戏开一张桌子，打开 **Games → Save & Load**，载入 **Guandan 掼蛋**。

只有房主需要这两个文件。在 Tabletop Simulator v14.2.2 上测试过。

## 语言

按钮和提示消息跟随每个玩家自己游戏的语言：游戏设成中文就显示中文，其他语言显示英文。同一桌的玩家可以各看各的语言。

我和朋友们都用简体中文玩。英文我做了适配，但没能充分试过，如果有小问题，很抱歉。

## 一局的流程

牌桌有四个座位：白、绿、紫、橙。

1. **选牌堆。** 桌上有两副牌，一副牌面是白底，一副是黑底。桌子中间的选牌堆圆牌显示的是将要发的那副牌的牌背，点它可以切换。
2. **发牌。** 点桌子中间的 **Deal** 圆牌。每个入座的玩家拿到 27 张牌，圆牌翻成 **Collect Cards**。
3. **出牌。** 见下面的按钮说明。
4. **收牌。** 点 **Collect Cards**。所有牌回到桌角各自的牌堆，洗好牌，圆牌翻回 **Deal**。如果还有玩家手里有牌，第一次点只会提示，5 秒内再点一次才会收。

每个座位还有一块 **Pass** 牌。骰子和两个计数器用来手动记分。

## 按钮

屏幕右下角有五个按钮。每个按钮都有一个脚本快捷键，默认是小键盘上的数字键，可以在 **Options → Game Keys** 里改。

| 按钮 | 快捷键 | 作用 |
|---|---|---|
| 正序 / 倒序 | 小键盘 1 | 把手牌排成一横排。按钮上写的是下一次点击会排成的顺序，每点一次轮换一次。 |
| 竖摞 | 小键盘 4 | 把手牌按点数摞成一列列。 |
| 选牌 / 出牌 | 小键盘 2 | 先进入选牌，再打出出牌区里的牌。 |
| 收回 | 小键盘 3 | 把出牌区里的牌收回手牌。 |
| 理牌 | 小键盘 5 | 把出牌区里的牌理成一组。 |

### 出牌

- **出牌区**是手牌前方桌面上画出来的方框。和手牌一样，里面的牌只有你自己看得见，并且会自动排好序。
- **选牌。** 点 **选牌**。之后点手牌里的牌，它进出牌区；点出牌区里的牌，它回到手牌。不选牌时也可以直接把牌拖进出牌区。
- **出牌。** 选牌时按钮会变成 **出牌**。点它，出牌区里的牌全部打出：正面朝上摆在你面前，从小到大排好。超过 10 张会分成几排。
- **收回。** **收回** 把出牌区的牌放回手牌，并结束选牌。
- 选牌状态下不能拖动自己的手牌，因为点击被用来移牌了。想拖牌先点 **收回**。
- 再次出牌或点自己的 **Pass** 牌时，你上一手的牌会被收到对应的牌堆。

### 竖摞

**竖摞** 把手牌摆成手机掼蛋那样：同点数的牌一列，列从 2 排到王，每张牌露出上边。

- 竖摞会一直保持。之后到手的牌（发的、收回的）会自动摞进去。
- 竖摞的牌由脚本固定住，所以不能拖。**左键点**一张牌，它进出牌区。
- 点 **正序 / 倒序** 恢复成一横排。

### 理牌

理牌是把打算一起出的牌放在一起，比如顺子。

- 把两张以上的牌放进出牌区，点 **理牌**。它们会在手牌左边单独摞成一列。
- **左键点**组里任意一张，整组进出牌区。到了出牌区它就不再是一组：可以出牌、收回，或者再理一次。
- 排序和竖摞都不会动理好的组。要改一个组，把它点进出牌区，增减牌之后再点 **理牌**。
- 可以同时有多组。

## 开发者说明

```
workshop/   mod 本身，游戏加载的就是它
src/        脚本、作为底本的原版创意工坊文件、生成脚本
tests/      脚本的测试
```

mod 文件是生成出来的。`src/build.py` 以 `src/original/` 里未改动的原版创意工坊文件为底本，注入 `src/` 里的脚本，加上出牌区和选牌堆圆牌，去掉原来的排序圆牌，并摆好桌面。只改写有变化的行，所以生成结果和原版之间的差异很干净。

**生成**（需要 Python 3）：

```
python src/build.py
```

这会写出 `workshop/3138177412.json`。想在游戏里试，可以把存档文件夹里的一个文件作为额外输出，图标会一起复制过去：

```
python src/build.py "<文档>/My Games/Tabletop Simulator/Saves/TS_Save_1.json"
```

**测试**（需要安装了 Tabletop Simulator，以及 .NET SDK 6 或更高版本）：

```
python tests/run_tests.py
```

测试用游戏自己的 Lua 解释器 MoonSharp 运行脚本，由 `tests/stubs.lua` 模拟游戏的接口。它检查的是脚本逻辑，不能代替进游戏实际试：物理、手牌区和界面只有在游戏里才是真的。

**文件说明：**

| 文件 | 内容 |
|---|---|
| `src/global.lua` | 出牌、选牌、排序、竖摞和理牌。设置项在文件开头。 |
| `src/global.xml` | 屏幕上的按钮。 |
| `src/collect_tool.lua` | 发牌 / 收牌圆牌。 |
| `src/deck_selector.lua` | 选牌堆圆牌。 |
| `src/pass_tile.lua` | Pass 牌。 |
| `src/build.py` | 生成脚本，以及桌上每样东西的位置。 |
| `tests/show_layout.py` | 列出生成的 mod 里每样东西在桌上的位置。 |
